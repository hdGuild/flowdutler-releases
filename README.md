# FlowDutler Releases

Dépôt public de distribution des versions Windows de **FlowDutler**.

Les sources de l’application sont conservées dans un dépôt privé. Les installateurs publiés ici sont générés automatiquement par GitHub Actions et accompagnés de leur empreinte SHA256.

Téléchargez la dernière version depuis la section [Releases](https://github.com/hdGuild/flowdutler-releases/releases/latest).
